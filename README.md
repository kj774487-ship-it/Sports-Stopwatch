# ⏱️ Chrono Sports Stopwatch

A sleek, high-precision digital sports stopwatch web application designed with an authentic Olympic stadium HUD console theme. Built with pure HTML5, CSS3, and JavaScript, it delivers millisecond-level timing accuracy, responsive 3D tactile controls, dynamic lap tracking, and integrated audio cues.

---

## 🌟 Features

- **Ultra-Precise Timing Engine**: Utilizes `performance.now()` and `requestAnimationFrame` for smooth, drift-free millisecond accuracy (`MM:SS.ms`).
- **Olympic HUD Design**: Realistic stadium backdrop, metallic console styling, neon speed streaks, and 3D tactile push buttons.
- **Smart Lap Recording**: Displays individual lap splits on a floating translucent HUD panel and dynamically highlights the fastest lap.
- **Audio Feedback**: Built-in Web Audio API sound effects for button clicks and timer events without external asset dependencies.
- **Keyboard Shortcuts**:
  - `Space` — Start / Stop
  - `L` — Record Lap
  - `R` — Reset Timer
- **100% Responsive**: Fully optimized for desktop, tablet, and mobile browsers.
